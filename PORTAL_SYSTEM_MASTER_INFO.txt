3. DATABASE ARCHITECTURE (SELF-HOSTED / ZERO-CLOUD-DEPENDENCY)
--------------------------------------------------------------------------------
The portal uses an ultra-fast, self-hosted, atomic JSON database engine
(backend/localDb.js). No external subscriptions (Firebase, MongoDB Atlas) needed.

* Remote Server Database Path: /var/www/levlox-portal/storage/data/
* Remote Uploads Path:         /var/www/levlox-portal/storage/uploads/
* Remote Backups Path:         /var/www/levlox-portal/storage/backups/
* Local Machine Data Path:     d:\portal\Levlox-Students-Portal\storage\data\

COLLECTION FILES BREAKDOWN:
- users.json            : Authentication credentials, roles, PBKDF2 salts & hashes.
- admins.json           : Super Admin profiles and system permission records.
- trainers.json         : Faculty profiles, employee IDs (TR-XXXX), specializations.
- students.json         : Student roster, roll numbers (STU-XXXX), fee ledger.
- courses.json          : Course catalog, syllabus modules, curriculum data.
- batches.json          : Batches/cohorts, trainer assignments, student rosters.
- liveClasses.json      : Scheduled/active live sessions, Google Meet/Zoom URLs.
- recordedClasses.json  : Recorded classes (YouTube Unlisted, Google Drive, MP4).
- playlists.json        : Video playlists grouping classes by subject/module.
- assignments.json      : Homework assignments, task instructions, attached PDFs.
- submissions.json      : Student assignment submissions, GitHub links, grades.
- attendanceSheets.json : Daily attendance register sheets per batch & date.
- attendance.json       : Individual student attendance logs.
- announcements.json    : Notice board alerts, broadcasts, hackathon updates.
- messages.json         : Batch community chat room discussions.
- sessions.json         : Active bearer login tokens.
- emailLogs.json        : Dispatch logs for welcome credentials and alerts.
- deletedUsers.json     : Audit trail of deleted accounts.
